# Jyotisha Engine

Deterministic calculation service. The LLM layer must never calculate planetary positions.

## Current implemented foundation
- Sidereal Swiss Ephemeris calculations
- Lahiri ayanamsa
- Whole-sign chart contract
- 9 Grahas including Rahu/Ketu
- Nakshatra + pada
- exact/approximate birth-time handling
- unknown-birth-time 24-hour uncertainty sweep

## Next calculation modules
D9 and Vargas, Parashari drishti, dignity, lordship, Vimshottari dasha, Ashtakavarga, yogas, gochara and transit-to-natal event extraction.
